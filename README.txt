DHEEPAY WEBSITE STARTER
=======================

Included pages:
- index.html       Homepage
- lite.html        Dheepay Lite product page
- enterprise.html  Dheepay Enterprise product page
- compare.html     Lite vs Enterprise comparison
- contact.html     Contact/enquiry form demo
- styles.css       Shared responsive styling
- script.js        Mobile navigation and demo form behavior

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Use the navigation to view the product pages.

PUBLISH
Upload all HTML, CSS and JS files to the same folder on your web host. Keep the file names and relative paths unchanged.
You can also deploy this folder to a static hosting provider.

IMPORTANT BEFORE LAUNCH
- Replace the demo contact form behavior in script.js with your actual email/CRM/backend integration.
- Update any product capabilities in the pages to match the features you will actually deliver.
- The product comparison is intentionally a positioning draft. Validate packaging, feature availability, integration scope and pricing before publishing.
- Add your privacy policy, terms, cookie notice (if applicable), and business contact details.
- The fonts load from Google Fonts; fallback fonts are included if unavailable.
- No customer logos, testimonials or performance statistics are fabricated.


BRAND ASSETS
